# Locus DemoMaker

A native macOS screen recorder that captures your display + cursor activity,
then renders a polished video with **smooth auto-zoom that follows the cursor**
— inspired by [screen.studio](https://screen.studio/).

Designed to be the fastest path from "press record" to a publishable demo clip.
No editor, no timeline, no fuss.

---

## Download

Grab the latest **`.dmg`** from
[Releases](https://github.com/leverageaiapp/locus-demomaker/releases/latest).
Drag **Locus DemoMaker** into Applications and launch.

> The current builds aren't notarized yet, so on first launch macOS will say
> *"Locus DemoMaker can't be opened because Apple cannot check it for malicious
> software."* Right-click the app → **Open** to bypass once.
> Notarization will land in a follow-up release.

On first launch you'll be asked to grant **Screen Recording** and
**Accessibility** permissions in System Settings.

## Architecture

```
record  ─►  source.mp4 + metadata.json  ─►  render  ─►  final.mp4
```

| Stage          | Component                                  | Tech                                       |
|----------------|--------------------------------------------|--------------------------------------------|
| Capture screen | `Recording/ScreenRecorder.swift`           | ScreenCaptureKit + AVAssetWriter (H.264)   |
| Capture mouse  | `Recording/MouseTracker.swift`             | CGEventTap (`cgSessionEventTap`)           |
| Auto-zoom      | `Rendering/ZoomKeyframeEngine.swift`       | Activity signal + critically-damped spring |
| Compositor     | `Rendering/AutoZoomCompositor.swift`       | Custom `AVVideoCompositing` + Core Image   |
| Cursor         | `Rendering/CursorRenderer.swift`           | Re-rendered crisp cursor + click ripples   |
| Export         | `Rendering/VideoExporter.swift`            | `AVAssetExportSession`                     |

Everything is post-processed: while recording we capture native pixels at 60 fps,
then in render we apply the zoom curve frame-by-frame. Keeps recording cheap
and the final result perfectly smooth.

### Auto-zoom algorithm

See `ZoomKeyframeEngine.swift`. Briefly:

1. **Activity signal** — clicks (+1.0), scrolls (+0.6), and fast cursor moves
   contribute impulses; impulses decay exponentially (half-life ≈ 1.2 s).
2. **Anticipation** — small forward look so zoom rises *before* a click, not after.
3. **Targets** — `zoom = lerp(idle, active, activity)`; focus tracks cursor when
   active, snaps to screen center when idle.
4. **Smoothing** — closed-form critically damped spring on focus (ω≈5.5) and
   zoom (ω≈3.0). No overshoot, no twitching on small mouse jitter.

## Build from source

Requires macOS 14+, Xcode 15+, and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
brew install xcodegen
./setup.sh                 # generates ScreenStudio.xcodeproj from project.yml
open ScreenStudio.xcodeproj
```

`./setup.sh` auto-detects an Apple Development cert in your keychain and
configures the project for stable signing — that way macOS TCC remembers
permission grants across rebuilds.

### Build a DMG locally

```sh
./scripts/build-dmg.sh
# → build/dmg/Locus-DemoMaker.dmg
```

### Cut a release

```sh
git tag v0.2.0
git push origin v0.2.0
```

The `Release` GitHub Actions workflow builds the DMG on `macos-14`, attaches it
to a fresh GitHub Release, and includes a SHA-256 checksum.

## Project layout

```
Sources/ScreenStudio/
├── App/                 — SwiftUI entry point
├── Models/              — MouseEvent, RecordingMetadata, RecordingItem
├── Recording/           — capture (screen + mouse + permissions + library)
├── Rendering/           — keyframe engine, compositor, cursor, exporter
├── UI/                  — SwiftUI views
├── Info.plist
└── ScreenStudio.entitlements
Resources/Assets.xcassets/
├── AppIcon.appiconset/  — generated by tools/generate-icon.swift
└── LocusLogo.imageset/  — brand mark used in the welcome screen
tools/
└── generate-icon.swift  — re-renders the app icon
scripts/
└── build-dmg.sh         — Release build → drag-to-install DMG
```

Recordings land in `~/Movies/ScreenStudio/Recording-<timestamp>/`
(`source.mp4` + `metadata.json`). Final exports go to a path you choose.
